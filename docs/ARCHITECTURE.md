# Архітектура

Докладний опис, схема потоку даних і відповідність пунктам завдання — у головному [README.md](../README.md).

## Складові

| Компонент | Контейнер | Призначення |
|---|---|---|
| Nginx | `nginx` | HTTPS, балансування запитів (least_conn) між API-серверами |
| API-сервери | `api1`, `api2` | FastAPI: авторизація, перевірка лімітів, історія, адмін-панель |
| Воркери | `worker1`, `worker2` або `auto-N` | Celery: рахують смуги зображення |
| Автомасштабувач | `autoscaler` | Запускає/зупиняє воркерів (мін. 2, макс. 4) |
| PostgreSQL | `postgres` | Користувачі, токени, задачі, зображення |
| Redis | `redis` | Черга Celery, прогрес, прапорці скасування, стан воркерів |

## Таблиці БД

- `users` — користувачі (хеші паролів PBKDF2)
- `auth_tokens` — токени входу (діють 24 години)
- `tasks` — задачі: параметри, стан, час, воркери, вхідне зображення і результат
